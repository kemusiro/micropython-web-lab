# 一軸アームの物理モデル（E3）

`src/physics/one-axis-arm.ts`は鉛直面内の一軸剛体を計算し、`arm-control.ts`は検証用のPD制御を行う。
どちらもDOM、描画、実時間、乱数、MicroPython、ストレージへ依存しない。
通常画面からの実行と表示は[E5の実験画面](arm-workspace.md)を参照する。ここでは数値モデルそのものを説明する。
採用理由は[ADR 0053](adr/0053-add-a-deterministic-one-axis-arm-model.md)を参照する。

## 座標と力学

一様な棒の長さL、質量M、先端の点質量mを使う。右向き水平を角度θ=0、反時計回りを正とし、
重力は下向きとする。内部計算はSI単位、角度はradを使う。

```text
J = M L² / 3 + m L²
G = g (M L / 2 + m L)
τ = clamp(τrequested, -τmax, τmax)
θ' = ω
ω' = (τ - G cos θ - b ω) / J
E = J ω² / 2 + G sin θ
```

Jは軸まわりの慣性、Gは重力トルクの係数、bは粘性摩擦係数である。
棒の各部分と先端質量の慣性・位置エネルギーを足した式で、質量ゼロの棒を仮定しない。
Eの基準は水平の静止状態なので、診断用の下向き振り子では負の値も正常である。
接触と摩擦がなければ、入力仕事τΔθと機械エネルギー変化を比較できる。

振り子と粘性減衰・入力トルクの考え方は[MITの振り子の講義](https://underactuated.mit.edu/pend.html)も参照できる。
同資料とは角度原点が異なるため、本モデルの重力項はcosになる。コードや図を転載したものではない。

## 標準条件

| 量 | 値・範囲 |
| --- | --- |
| 棒の長さ、質量 | 0.20 m、0.15 kgで固定 |
| 先端質量 | 既定0.15 kg、0〜0.60 kg |
| 重力、粘性摩擦 | 9.81 m/s²、0.012 N·m·s/radで固定 |
| 関節トルク上限 | ±1.20 N·m |
| 可動域 | 0〜150° |
| 初期角度、角速度 | 既定0°、0〜100°。角速度は0 |
| 目標角度 | 既定60°、10〜100° |
| Kp | 既定1.2、0.5〜3.0 N·m/rad |
| Kd | 既定0.040、0〜0.150 N·m·s/rad |
| 重力補償 | 既定なし、真偽値 |
| 実験長 | 既定6,000 ms、1,000〜10,000 msで10 msの整数倍 |

`DEFAULT_ARM_CONTROL`のフィールド名は`payloadMassKg`、`initialAngleRad`、`targetAngleRad`、
`kpNmPerRad`、`kdNmSPerRad`、`gravityCompensation`、`durationMs`とする。
検査は数値への暗黙変換をせず、NaN、無限大、欠落・未知のフィールド、単位の取り違えを拒否する。
数値だけで表した誤った単位は一般に識別できないため、範囲検査と単位付きの名前を併用する。

```typescript
import { DEFAULT_ARM_CONTROL, runArmControl } from "./src/physics/arm-control";

const result = runArmControl({ ...DEFAULT_ARM_CONTROL, gravityCompensation: true });
const last = result.observations.at(-1)!;
// last.angleRad、last.angularVelocityRadPerSなどを検証に使う。
```

これはホスト側の参照計算であり、利用者のPythonコードを実行する例ではない。
制御則は`Kp * (target - angle) - Kd * speed`で、補償ありの場合だけ`G * cos(angle)`を加える。
理想モデルのGが既知という条件であり、補償が行き過ぎを防ぐとは限らない。

## 固定刻みとストッパー

制御値を10 ms保持し、その間に1 ms刻みの古典的4次Runge–Kutta法を10回適用する。
4段の評価は角度と速度を一組として計算する。方式は[MITのRK4解説](https://web.mit.edu/10.001/Web/Course_Notes/Differential_Equations_Notes/node5.html)を参照できる。
比較用には0.5 ms刻みを選べるが、制御周期10 msは維持する。可変刻みや壁時計への追従は行わない。

各内部刻みの後で角度を可動域へ戻し、境界の外向きの速度だけを0にする。
境界で静止している場合、外向きの加速度は拘束し、内向きのトルクが勝てば離脱する。
反発、接触位置の厳密な時刻探索、衝撃力、静止摩擦は再現しない。
RK4もエネルギーを厳密保存する手法ではなく、検査した刻みと条件での誤差を示す。

`OneAxisArm`の物理パラメータ差替えは、無重力・無摩擦・下向き振り子・初速などの診断に用いる。
診断の角度境界は−π〜π内で、有限値、正の慣性、境界内の初期状態などを検査する。
外向き速度を持つ境界上の初期状態は拒否する。極端な診断定数での安定性まで保証するものではない。
実験の開始条件に指定できる変更は上の標準条件に限定する。

## 記録の意味

- `observations`はtick 0の開始状態と、積分後の各状態。時刻は`tick * 10,000 / 1,000,000`秒。
- `intervals`のtick nは[n,n+1)に作用した要求トルク、適用トルク、飽和と接触・速度投影のフラグ。
- 観測の加速度は直前区間の保持トルクで評価する。tick 0では要求0を使い、次の指令を予測しない。
- 静止拘束中の`accelerationRadPerS2`は0。速度投影のあった区間の終端は`null`とする。
  `unconstrainedAccelerationRadPerS2`は拘束反力を除いた力学式の値で、衝撃加速度ではない。
- `gravityTorqueNm`と`viscousTorqueNm`は式で差し引く符号付きの項。位置差分から速度・加速度を求めない。
- 最大1,000区間、1,001状態。`plannedTicks`と`status`で予定長と`running`／`completed`／`stopped`を区別する。

`read()`は時刻を進めず、`step(torque)`だけが一周期進める。`end()`後・上限後は進行を拒否する。
不正入力や非有限の計算結果で部分的なtickを確定しない。入力、読取、トレースは複製し、返却値の編集を
モデルへ逆流させない。結果にはモデル1.0.0、RK4の実装版1、物理パラメータ、積分刻みを記録し、
参照制御の結果には開始条件も含める。保存形式・Python API・WorkerメッセージはE3では追加しない。

## 数値検証

共通条件は初期0°、目標60°、棒0.15 kg、長さ0.20 m、Kp=1.2、6秒。
最大値は10 msごとの記録点の最大で、点間の真の極値ではない。次はNodeとChromiumでの計算結果であり、実測ではない。

| 条件 | 6秒後の角度 | 記録した最大角度 | 合意済みの照合基準 |
| --- | ---: | ---: | --- |
| 先端150 g、Kd=0.040、補償なし | 45.12957° | 65.14316° | 終了45.13° ±0.05° |
| 同じ条件、補償あり | 60.00000° | 87.26512° | 終了60.00° ±0.05° |
| 先端150 g、Kd=0.005、補償なし | 44.38494° | 85.06630° | 最大85.07° ±0.10° |
| 先端600 g、補償なし | 0° | 0° | 初期重力1.32435 N·mが上限1.20 N·mを超える |

1 msと0.5 msの角度系列の最大差は4ケースで3.3×10⁻⁹°未満だった（検査基準0.01°未満）。
同じ条件の再計算は同じ数値列となり、今回のNodeとChromiumの最大角度差は4.5×10⁻¹⁶ rad未満だった。
全ブラウザのビット一致、より長い実験、多関節や接触一般へ外挿しない。
有限時刻の終了偏差と定常偏差は区別する。特に低減衰の6秒後を、収束した角度とは断定しない。

単体では棒の慣性、初期加速度、平衡、等加速度・指数減衰の解析解、エネルギー保存と散逸、
外力の仕事、境界の両方向、飽和、記録の独立性、不正入力、長さ上限を検査する。
ブラウザではNodeとの比較、同条件の反復、刻み幅半減、ホスト処理を分割しても同じ結果になることを確認する。

```sh
./scripts/use-node.sh pnpm exec vitest run src/physics
./scripts/use-node.sh pnpm test:e2e:experiments
```

強制停止は[E4の実行基盤](arm-runtime.md)へ追加した。アーム描画と時系列グラフは[E5の実験画面](arm-workspace.md)で接続した。
