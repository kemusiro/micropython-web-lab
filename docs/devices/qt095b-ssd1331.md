# QT095B SSD1331 SPIデバイスモデル

## 対象

秋月電子通商の「0.95インチ 96×64ドット RGB OLEDディスプレイ」、型番`QT095B`、販売コード
`114435`を、Device API v1のSPI targetサンプルとして実装する。依頼時の呼称はTFT LCDだが、対象商品と
SSD1331は液晶ではなくRGB OLEDであるため、Web Labでは実際の表示方式に合わせて表記する。

- [秋月電子 商品ページ](https://akizukidenshi.com/catalog/g/g114435/)
- [秋月電子 QT095Bデータシート](https://akizukidenshi.com/goodsaffix/qt095b.pdf)
- [Solomon Systech SSD1331 Revision 1.2データシート](https://akizukidenshi.com/goodsaffix/ssd1331.pdf)

管理版Connection GraphはPico 2 WのSPI0へ次のように固定接続する。QT095B基板の信号名はデータシートの`SCLK`と
`SDIN`に合わせる。

| QT095B信号 | Pico 2 W | 用途 |
| --- | --- | --- |
| SCLK | GP6 | SPI0 SCK |
| SDIN | GP7 | SPI0 MOSI |
| CS | GP5 | アクティブLowのチップセレクト |
| D/C | GP2 | Low=コマンド、High=表示データ |
| RES | GP3 | アクティブLowのリセット |
| GND | GND | 共通GND |
| VCC | 3V3 | 電源（シミュレーションでは電気特性を扱わない） |

Pico 2 W Board ProfileのSPI0はMISO=GP4も要求するため、MicroPython作例では`Pin(4)`を指定する。ただし
表示器モデルは書き込み専用であり、MISO信号は使用しない。

## Device APIへの接続

モデル`org.micropython-web-lab.qt095b-ssd1331`は、既存Device API v1の`spi-target`を1ポート、
`gpio-observer`をCS、D/C、RESET用に3ポート提供する。CSをSPIポートへ暗黙に含めないというv1契約に従い、
GPIOのLow期間だけSSD1331へSPI0転送を振り分ける。CSが選択されていない転送は、既存のSPIレジスタ
リファレンスデバイスへ届くため、従来作例を維持できる。

内部フレームバッファは96×64のRGB565で保持し、次を機能レベルで処理する。

- 表示ON／OFF（`0xAF`／`0xAE`）
- 列・行アドレス設定（`0x15`／`0x75`）
- リマップ設定（`0xA0`）と水平・垂直アドレス増分
- RGB565表示データ書き込み
- ウィンドウ消去、線、矩形、塗りつぶし設定（`0x25`、`0x21`、`0x22`、`0x26`）
- コントラストなど作例初期化で使われる設定コマンドの受理

画面の「SSD1331 RGB OLED」作例は、表示器を初期化し、白枠と赤・緑・青の帯をRGB565で送る。Device API
v1のSPI転送上限256バイトに合わせ、12,288バイトのフレームを分割して送信する。

## 表示状態とUI

Device Stateは平坦なプリミティブ値と16 KiB以下という既存契約を維持する。RGB565そのものでは容量を
超えるため、UIプレビューには1ピクセル1バイトのRGB332へ決定論的に量子化した6,144バイトをBase64で
格納する。表示OFF中は同じ長さの黒画面を発行する。

管理版ホストだけが使う`pixel-display`部品は、96×64の固定CanvasへRGB332を展開する。最大16,384
ピクセル、固定符号化、完全一致するデータ長を検証し、Device ModelへCanvas、DOM、任意HTML、CSS、
JavaScriptを渡さない。この部品はInternal Experimentalであり、公開予定のDevice SDK v1契約にはまだ
含めない。判断理由は`docs/adr/0022-render-a-bounded-pixel-display-preview.md`を正とする。

## 意図的な制限

これは機能レベルモデルであり、次は再現しない。

- OLEDパネルの電圧、電流、輝度、寿命、焼き付き、色差
- SPI波形、転送時間、最大クロック、電源投入・リセット待ち時間
- SSD1331の全コマンドと全リマップ・色深度モード
- 256色モード、スクロール、表示開始線、部分表示、フェード／点滅
- VCC、GND、未接続、誤配線などの電気的異常
- ピクセルごとの高頻度な中間フレーム通知

モデルはCSがHighへ戻った時点で状態をまとめて通知する。これにより、1フレーム中の多数のSPI転送ごとに
Base64変換とメインスレッド描画を行わず、決定論的な最終状態を表示する。
