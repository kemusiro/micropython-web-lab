# ChatGPTへの楽曲変換依頼の例

曲名・機種・入力ファイル名を書き換え、利用できるVGM/VGZなどのログを添付する。
曲名や録音だけでは元の音色とレジスタ列を正確に移植する入力として不足する。
YSIIのPC-8801版などでも同名曲の別機種版を混同しない。
同梱プレイヤー・ベースドライバー・[WYM1仕様](ym2203-bin-format.md)を添付する。
私用楽曲をWebLabの配布サンプルへ追加する依頼ではない。

~~~text
添付の音源ログを、MicroPython WebLabのYM2203BinPlayerで再生するWYM1形式の
song.binへ変換してください。実際に変換を実行し、検証済みのダウンロード可能な
ファイルを作成してください。実行できなければ明示し、未実行の結果やハッシュを作らないでください。

対象曲: <例: イースII / To Make The End of Battle>
対象機種: <例: NEC PC-8801>
入力: <添付VGM/VGZ>
目的: 手元のWebLabでの再生テスト
添付: WYM1仕様、web_lab_ym2203_bin_v1.py、web_lab_ym2203_v1.py

1. ヘッダー・圧縮・音源種類／台数／クロック・命令・曲長・ループ・追加ヘッダーを確認。
   1台の4 MHz YM2203用でなければ停止し、対応できない理由や不足資料を示してください。
   他機種の同名曲への置換、他音源・PCMの無断省略はしないでください。
   出典と利用条件を確認し、公開・再配布の許諾と個人の再生テストを区別してください。
2. FM音色、SSGミキサー／ノイズ／エンベロープを含む全書き込みと同時刻順序を保持。
   録音からの推測や似た音色への置換は禁止。ログが不足する場合は説明してください。
3. 累積サンプルを保持し、絶対時刻を(samples * 1000 + 22050) // 44100でmsへ丸める。
   待ちごとの丸め、同時刻イベントの統合・並べ替えは禁止。
   元の総サンプル数と、実際に読んだ待ち時間の合計を照合してください。
4. ヘッダーはstruct.pack("<4sIII", b"WYM1", N, period_ms, 4000000)。
   イベントはstruct.pack("<IBB", time_ms, register, value)。
   1 <= N <= 131071、0 <= time_ms <= period_ms、非減少順、長さ16 + 6*N。
   I2CオペコードはBINに含めません。
5. リセット状態から再生できる初期設定を保持。終端でFM3chキーオフ、SSG3ch音量0。
   例として末尾待ち500msを加え、追加イベントと期間を報告してください。
   容量・期間の上限超過は無断間引き・切り詰めせず理由を説明してください。
6. 今回は「入力ログを先頭から終端まで1回」とする。
   WYM1に部分ループ位置はないため、元の途中ループを全体ループへ無断変更しない。
   元のループ指定と今回の扱いをJSONへ記録。音量追加ヘッダーや別クロック等を
   再現できない場合は、失敗理由または未再現条件を明示し、原曲同等と報告しない。
7. main.pyは添付プレイヤーを使う。I2C(0, scl=Pin(9), sda=Pin(8), freq=400_000)、
   アドレス0x44。DATA_FILE="music/song.bin"、REPEAT_MS=None、内蔵アンプ20%を初期値とし、
   player.inspect(DATA_FILE)とplayer.play(DATA_FILE, repeat_ms=REPEAT_MS, volume=20)を使用。
   曲固有プレイヤーや、BIN全体をPythonタプル配列へ展開する処理は不要。
8. conversion.jsonに曲名・機種・出典・作曲者／権利者（確認できたもの）、
   入力／出力SHA-256、クロック、入力・追加消音・出力イベント数、
   総サンプル・演奏期間・追加待ち時間・ループの扱い・未再現事項を記録。
   未確認の情報は推測せず未確認としてください。
9. 形式検証を実行し、可能なら添付プレイヤーで転送数と開始パケットも検証。
   元ログとイベント列、最大時刻、順序、N、長さ、SHA-256を照合。
   実際のブラウザで再生していなければ「未検証」と明示してください。
10. project.zipにmain.py、music/song.bin、conversion.json、
    添付と同じ版のlib/web_lab_ym2203_v1.py・lib/web_lab_ym2203_bin_v1.pyを格納。
    絶対パス、親ディレクトリ、外部通信、秘密情報を含めない。
    全体4 MiB以内。ZIP内一覧と検証結果を提示する。
    ZIP取り込みは既存プロジェクトを置き換えること、再生時は結線を有効にし
    スピーカーのミュートを解除することをREADMEへ記載してください。
~~~

生成された検証記録と実ファイルを確認する。プロンプトだけでは正確な変換を保証しない。
実機の音量バランス、msへの時刻丸め、タイマー・CPU連携に起因する差は残りうる。
