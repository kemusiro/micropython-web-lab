# 公開版の入口UIのレビュー

対象: `/lab/` の入口。サーバー、転送、配備設定の変更を含まない。

## 実装

- 初回はLEDコードを開いたままとし、「実行」→ `500`を`200`に変更 → 再実行の手順を維持。
  上部の「LEDを点滅させる」は実行ボタンへ移動する。ワークスペースからは従来のLEDコピーを開く。
- 「実験を選ぶ」は既存の題材パネルをダイアログ内で使う。カタログの代表3題材を先に表示し、
  「すべての実験を見る」の先に既存の分類・一覧を置く。準備中の書籍は代表例に含めない。
  初めて開くボタンは「この実験を開く」（英語はOpen this experiment）とし、320px幅でも一行で表示する。
  開く・新しいコピーを作る・切り替える処理は既存のものを使用。閲覧では保存内容も実行状態も変更しない。
- 「作業を続ける」は現在の作業名を表示し、同じコードと配線でワークスペースを開く。
  初回に自由に書きたい人もここを使う。再訪時の自動復元と最後の画面を保つ。
- 日英の説明を短くし、入口でWorkerやREPLを説明しない。閉じる・Esc・Tabで操作できる。

保存形式、URL処理、実行バックエンド、依存パッケージは変更していない。

| ガイドの案内 | 実装後の画面での案内 |
| --- | --- |
| 上部の「はじめの実験」 | 「LEDを点滅させる」。初回は既にコードを表示する。 |
| 「ワークスペースを開く」 | 「作業を続ける」。作業名を添え、自由なコード編集にも案内する。 |
| 入口の説明・スクリーンショット | 3つの入口と、ワークスペース前に選べる代表実験を追加。図1は更新候補。 |

| 「ボタンを試す」で新しいワークスペースタブへ進む | 現行は独立したボタン実験の簡潔な画面。今回以前からの差分として図4・図5も更新候補。 |
