# ADR 0032: 停止位置と上限付きグローバル変数をデバッグ画面へ表示する

## 状態

採用

## 背景

pdb互換デバッグ実行は端末へ現在位置を出力するが、コードエディタとの対応を目視で探す必要がある。
また式を端末へ入力すればグローバル値を確認できるものの、ステップごとの状態を一覧で追いにくい。
MicroPython v1.28.0のframeは`f_globals`を提供するが、`f_locals`は提供しない。

## 決定

- `debugger-paused`へ停止位置とグローバル変数スナップショットをまとめて載せ、プロトコルをv12へ更新する。
- スナップショットは名前、型名、`repr()`表示値に限定し、最大100件、各フィールドの文字数を制限する。
- pdb実装自身が使うグローバルは除外し、利用者コードが追加した値を表示する。
- 停止中はエディタを読み取り専用にし、論理行に対応するオーバーレイを表示する。
- 変数値はエディタ横のペインへ`textContent`で描画し、HTMLとして解釈しない。
- 再開時は停止位置と変数ペインを消去する。関数ローカル変数は対応しない。

## 結果

- GUIだけで現在の実行位置と主要なプログラム状態を追跡できる。
- `repr()`は利用者定義処理を呼ぶ可能性があるが、既存の実行時間制限とWorker再生成で復旧できる。
- 大きな値は256文字で省略され、101件目以降のグローバル変数は表示されない。
- ローカル変数が必要になった場合は、上流frame機能とランタイムビルド方針を再評価する必要がある。
