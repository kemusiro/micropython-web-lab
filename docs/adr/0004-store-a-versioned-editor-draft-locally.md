# ADR 0004: エディタ下書きをバージョン付き形式でブラウザへ保存する

- 状態: Accepted
- 日付: 2026-08-25

## 背景

M1のエディタ内容はページを再読み込みすると失われる。さらにMicroPythonのWorkerは、応答しない
コードから復旧するため破棄できることを前提としている。作例や利用者のコードを扱うには、
ソースコードの正本をWorkerのライフサイクルから分離する必要がある。

将来は複数ファイル、複数プロジェクト、オプションコンテンツ、クラウド同期を扱う可能性がある。一方、M2で
それらを同時に設計すると、まだ確定していないプロジェクト形式や認証方式まで保存APIへ固定して
しまう。

## 決定

M2ではコードエディタ一つ分の下書きだけを、ブラウザの`localStorage`へ保存する。保存値は次の
情報を持つJSONとする。

- スキーマバージョン
- ソースコード
- ISO 8601形式の保存日時

保存キーにも形式のバージョンを含める。読み込み時はJSONの構造、スキーマバージョン、ソースの
型と最大文字数、保存日時を検証し、不正または未対応の値をエディタへ適用しない。

入力後は短い待ち時間を置いて自動保存する。利用者は明示的に保存でき、保存値を消去して初期
サンプルへ戻すこともできる。ストレージへアクセスできない場合や容量超過時はコード実行を妨げず、
保存できないことを画面へ表示する。下書きをサーバーへ送信しない。

## 結果

- Workerの停止、再生成、ページ再読み込みを行ってもコードを復元できる。
- 保存形式の変更をスキーマバージョンで検出できる。
- 破損した値や将来バージョンを暗黙に読み込まない。
- `localStorage`は同期APIで容量も限られるため、M2の20万文字までの単一下書きに限定する。
- サイトデータの消去、プライベートブラウズ、ストレージ無効化では保存を保証できない。
- 複数プロジェクト、ファイル、オプションコンテンツ、IndexedDB、クラウド同期は後続判断とする。
