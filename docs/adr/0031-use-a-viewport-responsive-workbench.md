# ADR 0031: ビューポートへ追従するワークベンチを使う

## 状態

採用

## 背景

従来のアプリケーションシェルは最大幅1440pxに固定され、広いディスプレイで余白が増えてもコード編集や
REPLへ割り当てられなかった。また、各領域が内容の高さに従って伸びるため、エディタとREPLを行き来する
際の縦スクロールが多く、仮想デバイスとの同時確認もしづらかった。

## 決定

- シェルの固定最大幅を廃止し、全ビューポート幅へ追従させる。
- 幅960px以上では、エディタ／REPLと仮想デバイスの2列ワークベンチを動的ビューポート高へ収める。
- エディタ、REPL、仮想デバイスは、割り当てた領域の内部を個別にスクロールする。
- 補助的な複数行REPL入力は広い画面でコンパクトに表示し、主要な編集領域へ高さを優先する。
- 幅960px未満では意味的なDOM順を保った1列表示と通常のページスクロールへ戻す。
- レイアウト変更はCSSに限定し、Workerプロトコル、実行状態、Device Model、保存データを変更しない。

## 結果

- 1440pxを超える画面でもエディタ、REPL、仮想デバイスへ横幅を利用できる。
- 広い画面では主要な作業領域が同じ画面内に残り、領域間を移動するページスクロールが減る。
- エディタの縦リサイズは広い画面で無効になるが、ワークベンチが安定した高さ配分を維持する。
- 狭い画面では縦長になるものの、既存の操作順とタッチ操作に適した1列表示を維持できる。
