# ADR 0038: 音源操作をプロジェクト内のPythonドライバーへまとめる

- 状態: Experimental
- 日付: 2026-10-11
- 予約時間と同梱ライブラリの更新方法は[ADR 0046](0046-support-long-native-ym2203-playback.md)で更新。以下は当時の決定。

## 背景と選択肢

レジスタを直接操作する音源サンプルは長く、音色や旋律の変更箇所を見つけにくい。
I2Cへ音符・音色の高水準コマンドを追加する方法と、既存のレジスタ・予約命令を
Python側で組み立てる方法を比較し、後者を選ぶ。I2C契約とホストの音声境界を維持し、
利用者がドライバーを読んで編集できるようにする。

## 決定

正本はMITライセンスの`src/drivers/web_lab_ym2203_v1.py`とする。
通常画面で音源サンプルを開いたときだけ、`lib/web_lab_ym2203_v1.py`としてプロジェクトへ追加する。
組み込みモジュールやWorker専用の隠れたモジュールにはせず、通常のファイル保存・import・ZIPを使う。
サンプルはMIDIノート番号と`fm_tone`・`reserve`で旋律を指定する。
専用の実現性検証ページにはレジスタ操作の参照サンプルを残す。

公開Device API v1、Runtime Protocol 15、I2C契約v1、保存形式を変更しない。
本番の依存パッケージを追加しない。ドライバーの転送先も既存の許可されたI2C APIだけである。
新しいPython APIは実験用とし、破壊的変更では別モジュール版を用意する。

## 保存と編集

追加前にプロジェクトのコピーで容量上限を検査する。既存ファイル・未保存のドライバー編集・
同名モジュールによるimportの競合は上書きせず、サンプルを開かずに保存状態欄で案内する。
同一内容のドライバーは再利用する。サンプル用タブを作れない場合もライブラリを追加しない。

既存の保存済みサンプルは書き換えない。利用者が新しいサンプルを開くと新しいタブになる。
通常のimportキャッシュを維持するため、ドライバーの編集や差し替え後は再起動が必要である。
旧版への配布にはコードとライブラリを一緒にZIPへ含められる。

## 演奏と制限

3種類の独自FMプリセット、FM/SSG各3チャンネルの即時発音・停止、内蔵アンプ音量を扱う。
予約は1チャンネルのMIDIノート列・休符を指定し、最大1,024イベント・8秒を維持する。
全音符・期間・音域を検査してから、最大63イベントずつ転送する。
FMの最初の音は、直前に即時発音があってもキーオフして再発音する。
途中の転送で失敗した場合は、部分的な予約が残らないようモジュールのresetを試みる。
ホストの停止・例外消音、予約終了時のチップ停止は既存の実装を使う。

## 検証

固定版MicroPythonで正本ドライバーを実行し、生成したパケットを実デバイスモデルへ渡す。
音程・時刻・休符・転送サイズ、プリセットと全チャンネルのPCM、無効入力の事前拒否、
転送失敗時の予約解除を確認する。ファイル追加は競合・容量上限で元データを維持することを検証する。
ブラウザでは新しいサンプルのFM/SSG分離演奏、ファイル保存・import・再読み込み・編集保持を確認する。
