# ADR 0055: 一軸アームを通常の実験セットとして表示する

- 状態: Accepted（E5。配信は別工程）
- 日付: 2026-10-19
- 前提: [ADR 0052](0052-connect-experiment-sets-to-the-workspace.md)、[ADR 0054](0054-connect-micropython-to-a-simulation-worker.md)

## 選択と互換性

「ロボットと制御」と学習の入口に、重り付き一軸アームのひな型を追加する。
既存のセット保存・切替・ファイル・エディタを再利用し、別の保存領域や実行ボタンを増やさない。
モデル型は既存のボードRuntimeとは分け、E4の専用Workerペアで実行する。
ボードへ変換してから動かす代替案は、構成や権限が混ざるため採らない。

レコード版1とDB版2を維持し、明示的なモデル環境、SI単位のarm初期条件、fixed-step方針、arm-v1表示を追加する。
既存のボードレコードは変更しない。未知のモデル・版・表示と混在構成は拒否し、原データを保持して回収できる。
旧配布版はアームレコードを読めず復旧表示となる。アームを保存した後はE5対応版へ更新する。
新DBや全レコード版の更新はボードデータにも移行を要求するため採らない。
実行系列、Pythonの途中状態、閲覧tickはページ内だけに保持し、永続レコードに追加しない。

## 実行と表示

セットを開くだけではコードを実行しない。モデル型では実行要求ごとにE4のWorkerペアを用意し、
最新の保存済みファイル・条件と実行バッファを渡す。準備中・実行中は条件をロックする。
停止・切替ではペアを外部破棄し、受信済みファイルを既存の保存経路へ戻す。
非分離環境でもコード・条件・解説は閲覧でき、実行できない理由を表示する。
REPL・デバッグ・ボード配線はモデル型では利用不可と明示する。

SVGの固定ビューでアーム・重り・目標姿勢、角度と追加系列を表示する。描画ライブラリは追加しない。
描画は検査済みの確定観測だけをコピーして使い、物理計算・step・Workerの寿命を操作しない。
描画頻度と動きを抑える設定は観察だけへ作用する。
グラフとキーボード対応の時刻選択を同じtickへ結び付け、最新の計算時刻と記録の閲覧時刻を区別する。
加速度無効点を線で結ばず、要求・適用トルクは区間に対応した階段で表示する。

行き過ぎは目標方向を考慮し、終了偏差、飽和、接触と区別する。有限時間の偏差を定常偏差と呼ばない。
結果の条件とメタデータを固定し、後からコード・条件を変えた場合は変更前の結果と表示する。
セットを切り替えると記録を破棄し、再読込でも実行途中から再開しない。

## 検証

型付きレコードの往復・混在拒否、方向を含む指標、区間と観測の対応を単体で検査する。
通常画面で実WASMの実行、条件とバッファの保存・再読込、探索・表示切替、過去の時刻選択、
停止・再実行、非分離、狭幅、日本語・英語、明暗・動きの設定を検証する。
描画頻度を変えて同条件の全数値列が変わらないことを確認し、既存のREPL・保存・音源も回帰確認する。
