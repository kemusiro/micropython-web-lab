# ADR 0034: 初回はLEDの実験に集中できる画面を表示する

## 状態

採用

## 背景

エディタ、REPL、配線編集、全デバイス、サンプルを同時に表示すると、初めて使う人が
次の操作と結果を見る場所を選びにくい。コードの実行と編集による変化を小さな実験で体験させたい。

## 決定

- 保存済みコードのないブラウザは「はじめの実験」を既定とし、内蔵LEDの点滅コードを表示する。
- 実験画面では既存エディタ、実行ボタン、簡潔な内蔵LED表示、実行結果だけを中心に表示する。
  配線編集、デバイス一覧、REPL、デバッグ、詳細な保存操作は通常ワークスペースで利用する。
- 両画面で同じエディタとRuntimeClientを維持する。表示切り替えではWorkerを再生成せず、
  コード、Python変数、REPL入力途中の内容、配線、ペイン比率を保持する。
- 実験のLED表示は既存のGPIO状態通知から投影する。UIが点滅を演出したり配線を変更したりしない。
- 成功した実行中にLEDの点灯とその後の消灯を確認してから編集の案内へ進む。
  編集後の成功した点滅で次の作例への入口を示す。エラー、停止、無関係なコードでは完了にしない。
- 完了判定に端末文字列を使わない。RuntimeClientが識別子とWorker世代を確認した実行結果を利用し、
  再起動・停止時には進行中の実験を取り消す。
- 選択した画面のみを`micropython-web-lab:app-screen:v1`へ文字列`experiment`または`workspace`として保存する。
  既存のエディタ・配線の保存形式は変えない。設定なしの既存プロジェクトとローカルDevice開発は
  通常ワークスペースを既定とし、不正な保存データのエラーも通常画面に残す。
- 案内の進行はページ内の状態とし、再読み込みで最初の案内へ戻る。復元した編集内容は保持する。
  通常画面から実験を開く際は既存の実験タブを再利用し、なければ別タブを用意する。
- 編集案内はその実験の最初に成功したコードを基準とする。初期サンプルのままなら500から200への
  変更を案内し、編集済みなら数値や変数名を決め打ちせず点滅間隔の変更を案内する。
  編集途中で案内の目標を変えず、再読み込みや開き直しで保持されたコードにも対応する。
- 実験中の停止、起動失敗時の再起動、エラー出力を簡単な画面から操作できるようにする。
  実験の出力プレビューは末尾4,000文字に制限し、全出力は既存端末の上限内に保持する。
  新しい出力が追加されたらプレビュー内のスクロール位置を末尾へ追随させる。
- 次のボタン実験も簡潔な画面で続ける。既存Device UIの押しボタンだけを表示し、実行・停止を
  上部に置き、入力レベルと出力を近くに表示する。小さい画面ではコードより先に操作と結果を置く。
  ボタン実験の出力欄は表示開始時から高さ8remを確保し、最初の押下・解放でも結果ペインを伸縮させない。
  通常画面へ戻すと全デバイスの表示と元の折りたたみ状態を復元する。押しボタンが未接続なら、
  遷移時と実験の復元時に自動接続する。GP15を優先し、使用中なら空いているGPIOを選ぶ。
  既存ボタンの接続先と他デバイスの配線は保持し、サンプルには選んだGPIOを使う。
  接続追加時は既存の実行環境再生成を利用し、配線編集画面にも反映する。配線の保存に失敗しても
  そのセッションでは接続を有効にし、保存失敗を表示する。
- 実験の種類は独立した表示設定`micropython-web-lab:experiment-topic:v1`へ`led`または`button`として
  保存する。未設定・不正値は従来のLED実験とし、既存の画面選択・コード・配線の保存形式は維持する。
  進行状態は保存せず、復元したボタンコードは再実行できる。LEDへ戻ると既存の実験タブを再利用する。
  実験タブの関連付けはIndexedDBのワークスペース復元後に行い、古い退避用ジャーナルの
  アクティブタブを引き継がない。ボタン画面の表示設定だけでは通常タブを実験用とみなさず、
  日英の実験タブ名で復元先を確認する。対象がない場合は別タブにサンプルを作る。
  タブ上限で作成できなければワークスペースを表示し、別のコードを実験として実行させない。
- ボタン実験の完了には、実行中のモデル状態通知で押下後の解放を確認し、コードが正常終了することを
  要求する。通知の順序番号で重複・逆順を除外し、停止・再起動後の遅れた完了を採用しない。
  入力が未確認なら再試行を案内する。空きGPIOがなく自動接続できない場合と同期入力非対応時は理由を表示し実行を無効にする。

## 結果

初回の操作と観察対象を絞り、実行後の編集へつなげられる。依存パッケージ、Worker通信、
シミュレーションモデル、セキュリティ境界、コード・配線の保存形式は変更しない。
表示設定を保存できなくても画面の切り替えと停止・復旧は利用できる。
