# ADR 0030: 小さな型付きカタログでUIを多言語化する

## 状態

採用

## 背景

MicroPython Web Labの画面文言は、静的HTML、ランタイム状態、接続エディター、管理版Device UIへ
分散している。日本語と英語を追加するにあたり、翻訳漏れを検出でき、初期段階の静的配信と
依存ゼロの構成を維持できる境界が必要である。

## 決定

- `src/i18n/i18n.ts`へ英語の正本と、同じキーを必須とする日本語カタログを置く。
- 対応ロケールは`ja`と`en`に限定する。初回はブラウザ言語を使い、利用者の選択を
  `micropython-web-lab:locale:v1`へ保存する。
- 静的HTMLは`data-i18n`属性、動的文言は型付きの`t()`を使う。
- 言語変更時は保留中のコード保存を完了して再読み込みする。Workerプロトコル、接続グラフ、
  Device Modelの状態にはロケールを追加しない。
- Web Labが管理するDevice UI定義だけを英訳する。第三者Device packageの表示文字列は、
  パッケージ作者が提供した原文をそのまま表示する。
- 外部i18n依存は追加しない。言語数や複数形規則が増え、この方式で保守できなくなった時点で
  標準的なメッセージ形式またはライブラリを再評価する。

## 結果

- 翻訳キーの不足をTypeScriptで検出できる。
- 静的ホスティングと既存のセキュリティ境界を維持できる。
- 言語切り替えではページ再読み込みが発生するが、実行環境の状態と翻訳状態を分離できる。
- 第三者Deviceの翻訳責任はDevice package側に残る。
