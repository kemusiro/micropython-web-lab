# ADR 0052: 実験セットを右ペインと通常画面の保存経路へ接続する

- 状態: Accepted（ローカル実装。配信は別工程）
- 日付: 2026-10-19
- 前提: [ADR 0051](0051-add-transactional-experiment-set-storage.md)

## 背景と選択

デバイス名から作例を探す入口だけでは、何を試して何を観察できるかが伝わりにくい。
右ペインに用途、題材、作業画面を設け、コードと構成を一緒に開く。
コードを既存タブへ追加する方式は軽量だが、別の題材の配線やファイルを混ぜやすい。
複数Workerの常駐は途中再開できる一方、CPU・音声・メモリ管理が増えるため採らない。
既存の単一Workerを外部から停止し、保存基盤の原子的な切替に接続する。

## 画面とひな型

右ペインに5用途の入口、題材一覧、保存したセット、作業へ戻る操作を置く。
カテゴリは複数所属できるメタデータとし、セット内のコードタブとは別の選択単位にする。
作業画面は体験、構成、解説から成る。配線の専用ビューは既存実装を再利用する。

LED、ボタン入力、6秒間のボタン・LED連携、既存全デバイス、YM2203を提供する。
ロボット・制御と書籍の入口には準備中と表示する。物理計算や動作の演出は追加しない。
YM2203は既存の同梱ライブラリをコピーする。外部パッケージや任意スクリプトを読み込まない。
ひな型のID、版、内容のSHA-256をコピーへ記録する。表示言語は内容ハッシュへ含めない。
既存コピーを開く操作と新しいコピーの作成を分け、配布更新を利用者データへ自動適用しない。

初回の簡潔なLED画面と次のボタン画面を維持する。ただし作例はそれぞれ独立したセットとし、
24タブの既存作業へ新しいタブを押し込まない。同じセットの簡潔表示と通常表示の間は実行を維持する。
別セットを開く場合は停止を伴う。ADR 0034のタブ追加と自動配線の部分をこの決定で置き換える。

## 保存と切替

通常版は起動時に旧プロジェクトを一度移行し、ファイル、下書き、Pythonのチェックポイント、
配線の適用、表示設定、終了時退避をすべてセットに固定した保存ポートへ接続する。
旧IndexedDBとlocalStorageは保持する。移行トランザクションで旧レコードが見つかった場合は、
起動前に新規用ひな型を準備していても旧レコードを優先する。

適用中の配線と編集途中の有効な配線候補を別々に保存する。不正な途中入力は適用せず、
終了時退避もエディタだけを対象にする。`devices-v1`の表示設定へ省略可能な`collapsedDevices`を追加する。
省略時は全カードを展開する。既存版1レコードのDB更新は不要で、未知の表示フィールドを捨てる旧実装へ
戻した場合は折りたたみだけが失われる。未対応の実行環境・ボード・初期入力は勝手に代替しない。

閲覧だけでは停止しない。開く要求では能力確認後に編集・操作をロックし、保存を待ち、Worker破棄、
音声コンテキストの破棄、入力の初期化、一括確定、表示反映、新しい実行環境の準備を行う。
新しいコードは実行ボタンで開始する。起動に失敗しても確定済みの新セットを維持し、再起動できる。
保存に失敗した場合は元の編集と未保存印を保持する。過去のセット・世代の完了は反映しない。

保存キューは処理中1件と最新の待機1件に集約する。待機中の各呼出しは、最新内容の確定後に解決する。
明示的なファイル操作中は自動保存を延期し、反映前の古いファイル一覧で後続保存しない。
削除は未選択のセットに限り確認を求め、保存済みrevisionを照合して競合を拒否する。

## 復旧と制約

破損・未知の形式は読取専用で保持し、原データ、現在のファイル・バッファ、旧形式データを
JSONとして退避できる。JSONは回収用の版1形式で、取り込みは未実装。通常のZIPは保存済みファイル用で、
未保存バッファをファイルへ昇格させない。不正な旧配線だけは、利用者が明示した場合に既定配線で復旧する。
保存できない終了時退避や競合は表示し、保存成功と扱わない。保存の再試行は下書きを退避し、
ファイルへ反映しない。競合元を強制上書きする操作は設けず、両方の内容をJSONで回収できる。ブラウザ保存の削除・故障に備える別媒体への
バックアップは引き続き必要である。

ローカルDevice開発は固定された開発用構成を使うため、従来の単一プロジェクト経路を維持する。
移行済みオリジンの旧保存経路は拒否されるので、通常版とは別オリジンを使う。
DB版1を開く古い配布版への巻戻しはできない。戻し先にはDB版2とセット保存への対応が必要となる。
Worker通信、Device API、JavaScript権限、サーバー実行、本番依存パッケージは変更しない。

Chromiumのブラウザ統合で移行、実Workerの停止、音声破棄、競合、保存失敗、復旧、狭い画面を検証する。
保存容量付近の計測は16セット・60 MiBを使い、狭幅とCPU制限を併用するが、実機モバイルの代替とはしない。
Firefox・Safari・Edgeと実機モバイルの確認は配信前に別途必要である。
