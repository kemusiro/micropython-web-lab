# ADR 0050: YM2203の発声・MML・BINサンプルとイベント形式

- 状態: 採用
- 日付: 2026-10-12

## 決定

同梱の主要サンプルを発声比較、簡易MML、汎用BINプレイヤーとする。
既存の合奏・音色設定・Pocket Signalは追加例として残す。ゲーム固有コード・楽曲データを同梱しない。
MMLは短い学習用の明示的な部分集合とし、PMD等の互換性を主張しない。
各トラック8192文字・1024音符／休符、全体4096レジスタイベントまで。

BINは既存のuint32LE絶対時刻・レジスタ・値の6バイト列に、
16バイトWYM1ヘッダー（magic・イベント数・期間・4 MHzクロック）を追加する。
ヘッダーなしでは期間と数を曲固有のPython側へ重複記載する必要があり、
余計なデータや別クロックを検出しにくいため、この形式を採用する。
部分ループ・可変クロック・圧縮・CRCは今回の形式には追加しない。

## 互換性と境界

I2C契約、Worker通信、Device API、プロジェクト保存形式は変更しない。
新ライブラリは任意インストール、編集済みファイル・同名BINの衝突では上書きしない。
明示的バックアップ付き更新は既存の仕組みに統合する。
旧rawはplay_raw()で数と期間を明示して再生する。不正ヘッダーをrawと自動判別しない。

BINを2パスで検証・転送し、最大252バイトずつ読み、曲全体をPythonヒープへ展開しない。
転送失敗・割り込みはキューをリセットする。再生前の検証失敗は既存の状態を変更しない。
形状検証は完全性・真正性の保証ではない。変換記録のSHA-256を別途確認する。
